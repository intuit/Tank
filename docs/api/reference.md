# API Reference

This page documents every endpoint of the Tank REST V2 API: its parameters, request and response bodies, and status codes. See [Using the REST API](index.md) for the base URL, authentication, errors and paging.

!!! info "Generated from the code"
    The specification below is generated from the REST V2 controllers when this documentation is built, so it matches the code on `master`. A controller of a different version may differ.

    A running controller serves its own specification: the Swagger UI at `<tank_url>/swagger-ui.html` and the OpenAPI JSON at `<tank_url>/v3/api-docs`, where `<tank_url>` is the controller's base URL, for example `https://tank.example.com` (add `/tank` if the war isn't deployed as `ROOT.war`). Use "Try it out" there, against that controller, rather than on this page.
